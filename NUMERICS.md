# Numerical contract

## Characteristic function and drift convention

Spot 100, continuous r = 0.02, q = 0.01. Let X = log(S_T/S_0) - (r-q)T, and define φ(z,T) = E[exp(i z X)]. Thus this characteristic function is centered on the deterministic drift, not centered to mean zero; the variance correction remains inside it. For the declared negative-correlation box:

```text
b = kappa - rho*sigma*i*z
d = sqrt(b² + sigma²*(z²+i*z)), principal root with Re(d)>=0
g = (b-d)/(b+d)
e = exp(-d*T)
C = kappa*theta/sigma² * ((b-d)*T - 2*log((1-g*e)/(1-g)))
D = (b-d)/sigma² * (1-e)/(1-g*e)
phi = exp(C + D*v0)
```

This is the decaying-exponential form, not the branch-prone growing-exponential expression with the reciprocal g. Principal complex log and sqrt are used. The hand-built complex sqrt protects its mathematically nonnegative magnitude subtraction against roundoff, not option prices or variance states. No arbitrary price clipping or imaginary-part suppression is used. φ(0,T)=1, φ(-u,T)=conjugate(φ(u,T)), and |φ(u,T)|≤1 for real u are tested. Direct φ(-i) is outside the public helper domain; the independent reference uses it only in its separate stock-measure formula.

## Lewis integral

With φ excluding deterministic drift, the call price is

```text
Ccall = S*exp(-q*T) - sqrt(S*K)*exp(-(r+q)*T/2)/pi * I
I = integral_0^infinity Re[ exp(i*u*(log(S/K)+(r-q)*T))
                           * phi(u-i/2,T) ] / (u²+1/4) du
```

Putting drift inside φ instead requires different phase/prefactor placement. Mixing those conventions double-counts drift. The independent two-probability inversion checks this convention for all fixture quotes and box corners. r and q are not treated as equal or zero in those tests.

Production quadrature uses 16 Gauss-Legendre nodes per panel, with boundaries

```text
0, 0.5, 1, 2, 4, 8, 16, 32, 64, 96, 128, 160, 192, 224, 256,
288, 320, 352, 384, 416, 448, 480, 512,
576, 640, 704, 768, 832, 896, 960, 1024
```

Roots/weights are generated by Newton iteration on the Legendre recurrence, sorted ascending and reused. Characteristic-function values are shared across strikes at each expiry, not re-evaluated separately during calibration. Final pricing refinement uses 32 nodes on those panels and extends in steps of 64 through 2048. The maximum absolute difference across all 21 selected-fit quotes is shown. Finer panels at the same cutoff alone cannot reveal a missing tail, which is why the second cutoff is longer. This remains a difference diagnostic, not an a priori or certified absolute error bound.

Every returned call must be finite and lie between max(0, S exp(-qT) - K exp(-rT)) and S exp(-qT), with 1e-7 absolute allowance for roundoff/integration checks. A violation throws; the price is not clamped. The supported parameter box, strikes [80,120] and expiries [0.25,2] are hard scope. No universal Heston robustness claim, ξ=0 limit or zero-maturity branch is made.

## Fixture and noise

Presets `[v0,kappa,theta,sigma,rho]`:

```text
0: [0.045, 1.7, 0.050, 0.42, -0.62]
1: [0.070, 0.9, 0.032, 0.60, -0.78]
2: [0.025, 2.8, 0.065, 0.25, -0.30]
```

Clean calibration prices use 0.25, 1, 2 years, each with strikes 80,90,100,110,120 in that order. From integer seed 1..9999, advance unsigned `s = (1664525*s + 1013904223) mod 2^32` once per quote. Target = clean × (1 + noiseBps/10000 × (2s/2^32-1)). NoiseBps is finite in [0,100]. It is bounded relative price noise, not Gaussian, volatility noise, transaction cost or spread. It can break target static-arbitrage relations and is not repaired. At zero noise, seed cannot change targets. Neither generated truth nor six withheld prices enters `fit`.

Withheld prices are clean same-model calls at 0.5 and 1.5 years, each with strikes 85,100,115. They are interpolation points from the same invented model and numerical generator, not a real unseen dataset, temporal out-of-sample study or protection against model misspecification.

## Objective and optimizer

Mean squared price residual = sum((model-target)²)/15. No weighting, IV inversion, prior penalty, Feller constraint or truth penalty. RMSE = sqrt(MSE); withheld RMSE averages six clean residual squares independently. Largest calibration miss is max(abs(model-target)) across the 15 only. The Feller margin is `2*kappa*theta-sigma²`, not part of the objective.

The box is v₀ [0.02,0.09], κ [0.6,3.5], θ [0.02,0.09], ξ [0.15,0.75], ρ [-0.85,-0.15]. Decode each normalized coordinate by low + x*(high-low). Fixed starts in normalized space:

```text
[0.30,0.30,0.30,0.30,0.30]
[0.70,0.65,0.60,0.70,0.20]
[0.50,0.80,0.20,0.30,0.80]
```

Initial simplex: start plus +0.08 along each of the five axes. Each iteration sorts six vertices by increasing objective, stable on ties. Centroid excludes worst. Reflection coefficient 1, expansion 2, outside/inside contraction 0.5, shrink 0.5. Trial reflection/expansion/contraction coordinates are projected into [0,1]; shrunken points remain inside by convexity. Projection can collapse the simplex or trap a boundary fit, so a stopping flag does not prove stationarity or global optimality. Boundary count uses x≤1e-5 or x≥1-1e-5.

Stop only when max absolute coordinate difference from best across simplex <2e-5 AND worst-best objective spread <1e-10. Otherwise stop after 350 iterations, explicitly reported as budget cap. Evaluation count includes all six initial simplex grids and every reflected/expanded/contracted/shrunk grid, not reporting-only reprices or synthetic generation. Each trace stores best MSE at iteration start and the final best if changed. Select the lowest final MSE across three starts, stable first on exact tie.

Loss curve uses log10(max(1e-16,MSE)) only for drawing. Axes span floor(min log)-1 to ceil(max log)+1. No display floor feeds objective, stopping or metrics. Small numbers below 1e-6 display scientifically, otherwise six decimals in audits/four in summary. Price curves span zero to maximum target/fitted price+2. All curve coordinates use unrounded values.

## Verification and residual uncertainty

Java/JS tests cover all 32 parameter-box corners and deterministic interior points; call bounds, strike monotonicity/convexity, characteristic-function invariants and coarse/fine pricing. Complete results and all loss-trace fields are compared across languages. All three synthetic presets, zero/default/max noise and first/default/last seeds are included. Monotone best-loss trace, independently recomputed loss/summary/quote identities, no worse than initial loss, finite budget, target-copy snapshot and invalid/sparse inputs are tested. A finite grid does not prove all accepted inputs accurate.

Independent Python uses native complex arithmetic and SciPy adaptive two-probability inversion (separate stock/cash probabilities) through 2048, not the production Lewis contour or hand-built Legendre rule. It checks all corner test calls and every clean/fitted quote from nine full experiments at scaled 2e-7. Numerical Riccati ODE solutions verify complex characteristic-function values without its closed-form logarithm. Independent NumPy leggauss panels and SciPy bounded least-squares optimization reprice the final fits and bound the local improvement from the selected result below 3e-6 MSE on the nine fixtures. That comparison is not a global-optimum certificate and its empirical threshold does not become a runtime promise.

The gap may be near floating-point roundoff for default settings. That does not quantify model error, parameter uncertainty or integration error everywhere. Fits and targets are model-conditional, risk-neutral, synthetic and rounded only for display. No posterior probabilities, confidence intervals, returns forecasts or real trade recommendations follow from them.

Java result/trace arrays are mutable snapshots despite scalar immutable records. JS objects/arrays are mutable too. Target arrays are copied into each fit; fixed constants remain private. Browser worker submission is serialized; old applied results remain while new work runs, edits/resize do not apply, invalid controls/inspector retain prior state. Main content fits 320px; only the supplemental ledger scrolls. Native Safari/Android are untested.
